# Animal model credits

The low-poly animal models in this folder (`cow`, `llama`, `bull`, `pig`,
`stag`) are from the **Ultimate Animated Animals** / farm animal packs by
**[Quaternius](https://quaternius.com/)**, distributed via
[poly.pizza](https://poly.pizza/).

- Author: **Quaternius** — https://quaternius.com/
- License: **CC0 1.0 (Public Domain)** — free to use, no attribution
  required, but credited here with thanks.

Each `.glb` is a self-contained, rigged model with an idle animation, which
the game plays so the animals look alive as they ride the track.
